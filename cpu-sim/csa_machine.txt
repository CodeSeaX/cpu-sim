BASIC COMPUTER MACHINE (built in CPU Sim 4.0.11)
=================================================

Type: Mano's Basic Computer, microprogrammed, 16-bit, single accumulator,
      4096-word memory. Built for the Computer System Architecture lab
      (Practicals 1-11).

MACHINE FILE
------------
BasicComputer.cpu  (File -> Open machine in CPU Sim)
Bit indexing: from the left (CPU Sim bit 0 = leftmost bit = Mano's bit 15)
Program counter: PC

REGISTERS
---------
Name  Width  Purpose
AC    16     Accumulator
DR    16     Data register (memory operand)
AR    12     Address register
PC    12     Program counter
IR    16     Instruction register
E     1      Extended AC bit (carry out of ADD, rotated by CIR/CIL)
S     1      Start/stop flip-flop (HLT sets S = 1)
TMP   1      Scratch bit used inside CIR/CIL

CONDITION BITS
--------------
carry-E   register E, bit 0, halt = no
halt-S    register S, bit 0, halt = yes
Stop message: "EXECUTION HALTED NORMALLY due to the setting of the bit(s): [halt-S]"

RAM
---
M : 4096 cells, 16 bits per cell (word-addressed)

INSTRUCTION FIELDS
------------------
op      4 bits   opcode of memory-reference instructions
addr    12 bits  address of memory-reference instructions
opcode  16 bits  full code of register-reference and I/O instructions
(all required, absolute, unsigned, default 0)

FETCH SEQUENCE
--------------
PC->AR, M[AR]->IR, PC+1->PC, IR(0-11)->AR, decode-IR

INSTRUCTION SET (20 instructions)
---------------------------------
Memory-reference (format: op addr, direct addressing only)
  AND  0xxx   DR <- M[AR]; AC <- AC AND DR
  ADD  1xxx   DR <- M[AR]; AC <- AC + DR, E <- carry out
  LDA  2xxx   DR <- M[AR]; AC <- DR
  STA  3xxx   M[AR] <- AC
  BUN  4xxx   PC <- AR
  ISZ  6xxx   DR <- M[AR]; DR <- DR + 1; M[AR] <- DR; if DR = 0, PC <- PC + 1

Register-reference (format: opcode)
  CLA  7800   AC <- 0
  CLE  7400   E <- 0
  CMA  7200   AC <- AC'
  CME  7100   E <- E'
  CIR  7080   circulate E and AC right
  CIL  7040   circulate E and AC left
  INC  7020   AC <- AC + 1
  SPA  7010   skip next if AC >= 0
  SNA  7008   skip next if AC < 0
  SZA  7004   skip next if AC = 0
  SZE  7002   skip next if E = 0
  HLT  7001   S <- 1 (halt)

Input / Output (format: opcode)
  INP  F800   AC <- integer typed in the console
  OUT  F400   display AC as an integer in the console

NOTES ON THIS MACHINE
---------------------
- CIR/CIL use TMP: the bit leaving AC is saved in TMP, AC is shifted,
  the old E enters the vacated bit, then TMP is copied to E.
- Mano's AC(0) (LSB) is CPU Sim bit 15, and Mano's AC(15) (MSB) is bit 0,
  so the microinstructions AC(0)->TMP and AC(15)->TMP use
  srcStartBit 15 and 0 respectively.
- INP/OUT move a whole signed 16-bit integer, not an 8-bit character.
- No interrupt hardware (IEN, R, SKI, SKO, ION, IOF) and no indirect
  addressing (I bit always 0).

ASSEMBLER
---------
label: MNEMONIC operand ; comment
LABEL: .data 1 value     reserves one 16-bit word holding "value"
Run: Execute -> Assemble & load (Ctrl+2), then Run (Ctrl+R)
